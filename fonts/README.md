# Fonts

My favourite font at the moment is
[FiraCodeNerdFont-Regular](FiraCodeNerdFont-Regular.ttf)
so download it if you like and install with your system's font manager.

> [TIP]
> You may need to install a font manager e.g. `sudo apt install font-manager`
> where you can select the downloaded font to install for your system.

## Terminal

Remember to set the terminal font to be `Fira Code Nerd Font`, in your
terminal preferences once installed.
