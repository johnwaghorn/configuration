# 'Oh My Zsh!'

Oh My Zsh! is a popular zsh configuration framework. It comes with a lot of
plugins and themes. The starship prompt is a fast and customizable prompt that
can be used with Oh My Zsh!. This is a simple setup guide for Oh My Zsh! with
the starship prompt.

To follow this guide please follow the steps below in order.

## Prerequisites

- [Fira Code Nerd Font](../fonts/README.md).
- [zsh](../zsh/README.md)
- [Starship](../starship/README.md)

## Install 'Oh My Zsh!'

```shell
sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

## Run the setup script

To setup the Oh My Zsh! plugins and add the starship prompt to your zsh
configuration, you can run the following script.

```shell
chmod +x oh_my_zsh_first_setup.sh
./oh_my_zsh_first_setup.sh
```
